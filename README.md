# how-to

Guías para el How To de AFRUS: tutoriales paso a paso de cada módulo de la plataforma, en español, inglés y portugués.

Cada carpeta tiene un `README.md` con su índice, la guía en los tres idiomas (`*-guide.md`, `*-guide.en.md`, `*-guide.pt.md`) y los textos listos para pegar en afrus.ai/howto (`tutoriales-web*.md`).
